## 一句话定位

**StockChoose 是一个 Agent 驱动的 A 股研究与调度工作站，把行情、策略、财报、舆情、价值核算和交易计划放进一套可核查的桌面工作流。**

## 30 秒介绍

股票研究往往分散在行情软件、财报网页、新闻列表、筛选表格和聊天窗口中。StockChoose 用 Electron、React、TypeScript 和 Bun 把这些步骤放在一个 Windows 优先的桌面工作站里，并提供统一的 Agent 入口来查询数据、创建研究资源和切换业务频道。

当前版本适合个人研究者、策略学习者和希望扩展金融 MCP 工具的开发者。行情与新闻需要联网，Agent 需要额外配置；规则模拟不等同于真实历史回测，交易页也不是券商实盘接口。

## 可验证卖点

- Agent 可查询行情、公司资料、财报和公告，并创建策略、股票池和自定义因子。
- 六个业务频道共享同一工作区上下文，已支持的操作会返回执行回执。
- 策略、财报、新闻、估值和交易计划有独立领域服务和测试。
- Windows 优先的 Electron 桌面应用，Bun 负责本地 API 与数据调度。
- MIT 开源，保留真实数据不足、外部服务失败和未接入能力的明确空态。

这些表述只适用于当前仓库的已实现范围。发布前请按 [发布检查清单](launch-checklist.md) 再核对一次。

## 传播边界

- 不宣称“预测涨跌”“稳定盈利”“自动赚钱”或“替代投资顾问”。
- 不把当前规则模拟称为历史回测，不把演示数据称为实时行情。
- 不把 Agent 的外部运行时依赖写成“安装后自动可用”。
- 不把本项目的自愿心愿捐赠写成开发经费、投资或购买功能。
- 不公开本地 token、API Key、认证文件、个人持仓或带参数的接口地址。
